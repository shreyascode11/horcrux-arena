## 🔮 The Prophecy (Introduction)
**Education is boring. Magic is not.**

**Horcrux** transforms standard STEM learning into a high-stakes Wizarding World adventure. Unlike traditional quizzes that use static databases, Horcrux uses **GenAI (LLMs)** to instantly generate unique questions on *any* topic—from "Quantum Physics" to "The History of Magic"—ensuring no two duels are ever the same.

Students don't just "study"; they enter the **Arena** to duel peers, join **Squads**, and consult the **AI Oracle** for personalized career roadmaps.

---

## ✨ Key Features

| Feature | Description |
| :--- | :--- |
| **⚔️ 1 vs 1 Duels** | Real-time matchmaking using **Socket.io**. Challenge a rival wizard on any topic. Speed and accuracy determine the victor. |
| **🛡️ Squad Battles** | Form a private room (The Order of the Phoenix). Share a room code for group study sessions or tournaments. |
| **🤖 GenAI Question Engine** | Powered by **Groq/Llama-3**, the system generates fresh, context-aware questions instantly. Zero repetition. |
| **🔮 AI Career Oracle** | An intelligent agent that analyzes your skills, grades, and interests to prophesy your ideal career path and roadmap. |
| **📜 The History** | Your personal archive. Tracks battle history, win rates, and learning progress stored permanently via LocalStorage. |
| **🌘 Dark Magic UI** | A fully immersive, glassmorphism-based Dark Mode interface designed for late-night hacking (and spellcasting). |
