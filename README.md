# ⚡ Horcrux - The Wizarding Quiz Arena

**Horcrux** is a real-time, multiplayer battle platform that gamifies education. Unlike standard quizzes, Horcrux uses GenAI to instantly generate unique questions from any text topic or uploaded PDF lecture notes.

![Project Status](https://img.shields.io/badge/Status-In%20Development-purple)
![Tech Stack](https://img.shields.io/badge/Stack-MERN-blue)

## 🔮 Key Features

* **⚔️ 1 vs 1 Duels:** Instant matchmaking based on interest topics (e.g., React, History).
* **🛡️ Squad Battles:** Create private rooms (`Room Code`) for group study or tournaments.
* **📄 PDF-to-Quiz Engine:** Upload any document, and our AI extracts questions for the battle.
* **✨ Dark Magic UI:** A fully immersive, glassmorphism-based dark mode interface.

## 🛠️ Tech Stack

* **Frontend:** React.js, Tailwind CSS
* **Real-Time Engine:** Socket.io (WebSockets)
* **Backend:** Node.js, Express
* **AI Integration:** (Gemini/OpenAI - *Coming Soon*)
